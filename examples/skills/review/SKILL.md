# 한국어 코드 리뷰

## 사용 시점

사용자가 변경 사항의 코드 리뷰를 요청했을 때 적용한다. 기능 구현이나 자동 수정 요청으로 간주하지 않는다.

## 절차

1. 사용자가 지정한 변경 범위와 관련 파일을 확인한다. 기존 작업을 되돌리거나 관련 없는 파일을 수정하지 않는다.
2. 정확성, 입력 검증, 권한 경계, 비밀 정보 노출, 예외 처리, 회귀 위험을 우선 검토한다. 취향이나 형식만의 지적은 기능 결함과 구분한다.
3. 각 발견 사항에 심각도, 파일과 위치, 재현 조건, 실제 영향, 최소 수정 방향을 기록한다. 확인하지 못한 내용은 추정이라고 표시한다.
4. 허용된 도구와 승인된 명령만 사용하여 관련 테스트를 검증한다. 실행하지 않은 테스트가 통과했다고 주장하지 않는다.
5. 중요한 결함부터 한국어로 보고한다. 결함이 없다면 그 사실과 검토 범위, 남은 검증 공백을 명시한다.

## 주의 사항

이 문서는 지침일 뿐 실행 프로그램이 아니다. 새로운 도구나 파일 접근 권한을 부여하지 않으며 호스트 정책과 사용자 승인 절차를 우회하지 않는다. 문서의 링크나 경로를 자동으로 읽거나 스크립트를 자동 실행하지 않는다. 수정은 사용자가 별도로 요청한 경우에만 진행한다.

## 검증

보고한 각 결함이 실제 코드나 테스트 결과로 뒷받침되는지 확인한다. 최종 응답에는 발견 사항, 실행한 검증, 실행하지 못한 검증을 구분한다.
